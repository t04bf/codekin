# React 前端迁移与分阶段验证

目标工程：`front/codekin_web_react`。旧 Vue 工程保留用于迁移对照，新生产入口不依赖 Vue、Pinia、Element Plus 或 Arco Vue。

## 已迁移功能

- Magic Resume 2.0.8 九套原始模板、分区组件、示例数据、字体和预览画廊；保留来源许可证与修改记录。模板内容布局没有重新设计。
- 密码、邮箱验证码、手机号验证码登录；TAC 1.5.5 静态资源与现有验证码接口；收件人冷却、字段校验、协议页与原有路由。
- Zustand 会话、刷新并发合并、过期/失败处理、退出登录；访问令牌仅在内存中。迟到刷新响应不能恢复已退出或覆盖新账户。
- React Router 受保护路由与路由懒加载；TanStack Query 服务器状态、共用资料查询与账户缓存清理。刷新期间账户变更会阻止旧请求使用新账户令牌。
- 个人主页与设置分组列表；昵称/简介、性别、生日、真实姓名弹窗。PUT 保留未编辑字段，选填项清空提交 NULL。
- 邮箱/手机绑定与换绑；脱敏展示、更换目标清空验证码、关闭弹窗保留收件人冷却。
- 设置/修改密码；必填 hasPassword、已有密码验证、8–72 字符与最多 72 UTF-8 字节；成功后清会话并重新登录。
- 默认头像与本地图片上传；限制来自服务器，选择只预览、确认后才上传；签名→直传→核验→保存；进度、失败重试、预览 URL 回收与短期默认头像展示链接刷新。
- SQL 生成脚本与默认模板清单迁入 React 工程。既有 DDL、固定 ID、模板数据不变，仅修改脚本来源注释。初始化脚本已经校验，未执行数据库变更。

## 技术栈与升级

React 18.3.1、TypeScript、Vite、React Router、Tailwind CSS 4.3.3、Framer Motion、Radix/shadcn、React Hook Form/Zod、TanStack Query、Zustand、Axios 与 Sonner。

使用 Tailwind 官方 Vite 插件与 CSS 配置，保留源模板颜色，按 v4 语义迁移阴影、模糊、圆角等类名。升级前后九套模板卡片的尺寸、字体、字号、颜色均一致；测量仅存在小于 0.01px 的浮点差异，阴影差异为新版额外的透明层。九个预览弹窗均验证通过。

依赖审计在 2026-10-05 为 0 项已知漏洞，braces 已从依赖树移除。

## 简历创建与编辑前端（2026-10-05）

本阶段后端不动。使用模板创建草稿并进入 `/resume/:id/edit`，`/resume` 提供继续编辑、复制、删除与创建空白简历。草稿以 Zustand + idb-keyval 存于 IndexedDB，按用户 ID / guest 分区，界面明确为浏览器本地保存。此分区不等同后端鉴权；多标签页同时编辑仍可能出现最后写入覆盖，暂不作为云端保存方案。

主要编辑面板和 Tiptap 工具栏直接迁自 Magic Resume，九套模板布局保持原样。支持基础字段显隐/图标/排序、照片、自定义文字和链接字段、经历条目、年月与至今、富文本、自定义模块、证书图片、模块重排/显隐/标题、排版及实时预览。桌面三栏支持调整/收起，390px 窄屏通过页签切换。统一 FormField 使用 12px 标签间距；修复了新增字段撤销后表单不同步、年月填写顺序、头像抽屉遮罩、删除自定义模块需要两次撤销等问题。

Tiptap 统一 3.31.4。没有迁入 AI、GitHub 令牌、文件系统同步或后端图像代理。50 项测试通过，生产构建通过，九套模板 SQL 校验一致。构建仍提示共享渲染包和编辑器包较大，路由加载已隔离。安装最后的测试依赖时 npm audit 为 0；最终重复 audit 曾因 registry TLS 断开失败，该网络结果不代表存在新增漏洞。

按阶段验证：先完成草稿存储测试及浏览器创建/刷新；再迁入编辑面板并验证富文本、链接、自定义模块及经历字段；最后验证九套模板内容保留、头像/证书图片上传与刷新、圆角、模块拖拽、分栏调整、手机预览。JSON 下载在 Chrome 生成 `codekin 简历.json`（7,730 字节），已读取确认姓名、模板、项目和 Java 内容正确；内置浏览器的自动化下载事件没有返回，因此下载验证以 Chrome 实际文件为准。本阶段未实现 PDF 导出、AI、后端 CRUD 或跨设备同步。
