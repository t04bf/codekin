# Codekin 默认头像 · 第一套

12 款独立头像，保留吉祥物的圆润方脸和折角元素，用表情、配色和配件区分用户。由内置 image_gen 生成。

- `avatar-*.png`：12 张独立 512 × 512 PNG，奶油白背景。来源裁切约 305 × 305，512 为导出尺寸。
- `overview.png`：整套原始预览。
- `manifest.json`：稳定 ID、中文名称与文件名，可用于头像选择器。
- `prompt.txt`：生成提示词。
- `export.py`：整张原图裁切导出脚本，无肢体或五官拼接。

建议选择器使用圆角方形预览，与原头像造型一致；圆形展示需检查配件裁切。用户可在“上传头像”和“默认头像”之间选择。这次仅交付图片资源，尚未接入个人资料页面。
