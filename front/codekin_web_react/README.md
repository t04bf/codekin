# Codekin React frontend

独立 React + TypeScript + Vite 工程；Tailwind CSS + Framer Motion；Radix/shadcn UI；React Router。旧 Vue 工程只供迁移对照，不会被加载。

## Local development

Node.js 22.12+，npm。`npm ci`，`npm run dev`。默认 http://127.0.0.1:5174/resume/templates。API 默认代理至 http://127.0.0.1:8080；可用 DEV_API_TARGET 覆盖，线上使用 VITE_API_BASE_URL。

`npm run build` 执行 TypeScript 检查与生产构建；`npm test` 执行 Vitest 测试。

## Verification and boundaries

Vitest 测试覆盖模板、自定义字段渲染、登录验证、刷新竞争、路由保护、账户缓存与请求隔离、资料更新、联系方式、密码、头像裁剪及简历证件照直传流程。真实短信/邮件发送和真人滑块尚待联调；头像裁剪的浏览器业务流程使用模拟接口。真实 SeaweedFS 签名 POST 与 CORS 已另行验证，见证件照直传接口文档，不代表所有业务保存流程已经实测。

`npm run dev:fixture` 在 5175 启动独立 MSW 浏览器验证环境，用于个人资料/联系方式/头像/简历的视觉与操作验证。它只处理示例账号，不请求真实后端，也不进入生产入口或构建。其中测试专用简历数据库用独立存储键模拟服务端跨页面保存，不属于生产简历存储。直传模拟校验原始文件字节数、MIME、表单字段、file 排在最后及不携带应用 Authorization，上传成功后才允许确认。示例图片为项目资产。生产应用仍在 5174，默认走实际 API 代理。

两项开发服务使用不同的 Vite 预构建缓存目录，避免并行运行时互相覆盖缓存并产生重复 React 实例。

头像选择框将当前头像与默认头像分区展示。上传本地图片后进入独立裁剪视图，不展示默认头像列表；使用 [react-easy-crop](https://github.com/ValentinH/react-easy-crop) 拖动、缩放，右侧 Canvas 根据同一像素裁剪区域实时显示圆形预览。确认时输出最长边不超过 512 的方形 PNG，不放大小图片，并以裁剪结果的 MIME/大小申请签名、直传和确认；取消或失败保留原头像，重新上传释放旧本地预览。图片格式、原始大小/像素和裁剪文件大小沿用后端策略，后端接口保持原契约。

新增 6 项测试验证裁剪像素坐标（避免误用百分比）、预览与上传区域一致、方形 PNG 尺寸、不放大、源图尺寸与编码失败、当前头像分区和取消/替换。内置浏览器使用实际项目 PNG 验证拖动、缩放、预览、确认及重新打开；模拟接口保存实际上传的裁剪图片，确认结果为 446 × 446，原图为 450 × 600。截图位于 `dosc/images/react-avatar-crop.png` 和 `react-avatar-separated.png`。

访问令牌仅保留在内存中；只沿用原项目的 Refresh Token 存储键。账户资料与简历不持久化到浏览器；简历编辑状态仅保留在内存中。账户切换与退出清除 TanStack Query 私有缓存，改密成功后清除会话并重新登录。

模板 SQL 生成入口已迁至本工程；`npm run check:resume-sql` 校验，`npm run generate:resume-sql` 更新 `deploy/deploy.sql` 与独立初始化脚本。已保留原有数据库数据与 DDL，仅更换生成来源标注。数据库内容 JSON 与模板渲染模型通过显式适配器转换，共用 `contracts/resume/resume-document.schema.json` 校验结构。

已按路由拆包，模板元数据与渲染组件分开。原始九套渲染组件共享包约 730 kB（gzip 178 kB），编辑器包约 608 kB（gzip 186 kB），仍有构建体积提示；登录/资料不预加载这两个包。源字体完整保留，后续可按实际语言和字体需求精简。2026-10-05 的 npm audit 结果为 0 项已知漏洞，braces 已从依赖树移除。

## Resume editor

`/resume` 为当前用户的服务端简历列表；`/resume/templates` 创建简历；`/resume/:id/edit` 使用服务端 ID 打开编辑工作台。创建成功前不注册临时简历，失败刷新列表，不自动重试 POST。

保留 Magic Resume 原有编辑面板与模板布局：基本信息、照片尺寸与圆角、字段图标/显示/排序、自定义字段文字或链接、教育经历、工作经历、项目及项目链接、技能/自我评价富文本、证书图片、自定义模块、模块标题/顺序/显隐、主题色、字体/字号/行高/间距/模式。桌面使用可调整的三栏，窄屏切换模块、编辑和预览。支持撤销/重做、服务端简历复制/删除和手动 JSON 导出；尚无 PDF 导出或 AI 功能。

Tiptap 依赖统一至 3.31.4，保留原工具栏和 HTML 数据契约。编辑是即时更新模型的控件，不涉及提交整份表单；字段适配复用统一 FormField 12px 间距、Radix/shadcn Input/Switch。单日期输入沿用 Magic Resume 的 HeroUI DateInput，分段编辑年份和月份，输出 YYYY/MM；日期范围仍使用原生月份输入。已有账号表单继续使用 React Hook Form + Zod。自动保存使用 800ms 防抖和串行 PUT。保存失败显示重试，待重试请求仅保留在内存中；重试复用载荷、并发版本和 mutationId。版本冲突暂停自动保存，可先导出 JSON 再确认读取最新版本。离开未保存页面由 beforeunload 提示；刷新后从后端读取。账号切换清空内存状态及撤销历史。GitHub 令牌配置未迁入编辑器，请求转换会排除 githubKey。

测试覆盖无浏览器存储读写、刷新后的空内存状态、账号切换、新建成功前不出现临时记录、新建失败不留下本地记录、复制读取服务端数据，以及自动保存、串行更新、失败重试、冲突处理、模板切换、自定义模块与撤销重做。

证件照本地上传已接入 `RESUME_PHOTO`：登录后从后端读取限制，按签名 → 原始文件直传 → 确认的顺序处理，显示进度并防止重复提交；失败保留原照片，确认成功才更新本地图片。新增 7 项相关测试和隔离浏览器文件上传验证。简历保存文件 ID，详情接口返回两小时有效的私有访问 URL；上传的 Base64 预览及临时签名 URL 不写入正文。在线图片链接与证书图片继续保持原有方式。
