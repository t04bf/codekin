# 前端开发要求

本文件适用于 `front/codekin_web_client/`。

- 布局、输入、选择、日期、按钮、弹窗、菜单和提示优先使用已安装的第三方组件，不自制原生控件或重复实现组件库样式。
- 所有页面和弹窗的操作成功、接口失败、业务失败、网络异常统一用 `ElMessage.success/error/warning` 提示，禁止将操作结果做成页面或弹窗内的 `ElAlert` 或结果文案块；同一错误避免重复提示。跨页面提示不使用持续展示的 URL 标记；兼容旧标记时消费后立即清除，避免刷新重复提示。字段格式、必填等表单校验继续使用组件库的字段校验提示；协议草案、操作影响等静态说明属于页面内容。
- 保留已确认的页面布局和交互；替换控件不代表可以重新设计整个页面。个人资料使用分组列表，点击整行打开编辑弹窗，页面不铺开表单或描述表格。
- Element Plus 加载完整 CSS 并配置中文语言，Arco List/Grid 按需加载组件 CSS。全局主题只维护品牌颜色、圆角、透明头像背景和基础重置。布局尺寸优先使用组件属性；必要的最大宽度、居中高度及卡片内边距可通过组件的布局属性配置，不自制控件样式或重写整个页面 CSS。
- 没有头像访问接口时使用 `src/assets/mascot-avatar.png`（来自 `design/codekin/brand/mascot-avatar.png`），通过头像组件展示并保留简单边框。品牌 Logo 与用户头像分别使用各自资源，透明品牌图片不可套用组件默认灰底。
- 手机号、邮箱展示沿用脱敏工具；密码、验证码不记录日志、不持久化。沿用统一 Axios 和已有令牌刷新封装。
- 设置密码根据本人资料接口返回的必填布尔值 `hasPassword` 判断；字段缺失按接口响应错误处理，不当作 `false`，不展示误导性的设置入口；已设置时必须输入旧密码。密码成功保存后清除旧登录态并重新登录，与后端撤销会话规则一致。
